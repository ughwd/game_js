# 狸 Тануки и сакэ

Браузерный платформер на ванильном JS + Canvas. Тануки собирает 3 бутылки сакэ и добегает до тории,
а кицунэ бегает по небу и роняет лисьи огни. Падение в пруд или касание огня — поражение.

## Управление
- Бег: ← → или A / D
- Прыжок: Space, W или ↑ (в воздухе повторно прыгать нельзя)
- Кнопки: Старт / Пауза (Продолжить через «Старт») / Заново
- На телефоне — экранные кнопки ◀ ▶ и «Прыжок» (поддерживают удержание)

## Запуск
ES-модули не работают по `file://`, нужен локальный сервер:
```
python -m http.server 8000
```
и открыть http://localhost:8000. Либо расширение Live Server в VS Code.

## Публикация на GitHub Pages
1. Создай репозиторий и загрузи все файлы в корень.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту игра откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
